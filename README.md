# AI-Assisted GitHub QA - Arduino LED Blinking

## Project Overview
This project demonstrates an Arduino LED blinking program and the use of GitHub for QA documentation, issue tracking, AI-assisted debugging, and project management.

## Objectives
- Create a basic Arduino embedded-code project.
- Use AI tools to assist with code review and debugging.
- Record QA issues and their resolutions.
- Demonstrate GitHub Issues, branches, and pull requests.
- Document testing and project progress.

## Hardware
- Arduino-compatible board
- Built-in LED or external LED
- USB cable
- Computer with Arduino IDE

## Project Files
- `led_blink.ino` - Arduino source code
- `QA_ISSUES.md` - QA issue register
- `AI_PROMPT_LOG.md` - AI prompt and verification log
- `TEST_RESULTS.md` - Test procedures and actual results

## How It Works
The program toggles the LED approximately every 500 milliseconds using `millis()`.

## Testing
Actual test results and supporting evidence will be recorded in `TEST_RESULTS.md`.
