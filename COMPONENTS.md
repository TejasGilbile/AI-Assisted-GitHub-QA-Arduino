# Components & Materials List

- **Arduino Uno Microcontroller** (1x)

- **LED (5mm Red)** (2x)

- **Resistor 220Ω** (2x)
  - ¼ Watt carbon film resistor
  - Limits current to safe LED level (~20mA)

  - Male-to-male connecting wires

- **USB Cable A-B** (1x)

## Safety Guidelines

⚠️ **Important Safety Notes:**

1. **Voltage Safety:** Arduino operates at safe 5V (not dangerous)
2. **Current Limiting:** Always use resistors with LEDs
3. **Polarity:** Respect LED polarity (anode/cathode)
4. **Heat:** Components remain cool to touch
5. **Soldering:** This project doesn't require soldering
6. **No shorts:** Don't connect pins directly without resistors

## Component Specifications

### Arduino Uno
- Operating Voltage: 5V
- Digital I/O Pins: 14 (6 with PWM)
- Current per Pin: 40mA max
- Total Current: 200mA max

### LED (Standard Red)
- Forward Voltage (Vf): 1.8-2.2V
- Maximum Current: 20-25mA
- Brightness: ~1000-2000 mcd
- Wavelength: 620-625nm

### Resistor (220Ω)
- Resistance: 220Ω ±5%
- Power Rating: ¼W minimum
- Current Limiting: 5V ÷ 220Ω = ~23mA
